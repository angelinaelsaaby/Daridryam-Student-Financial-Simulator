# Daridryam – Student Financial Survival Simulator

## About the Project
Daridryam is a Java-based Student Financial Survival Simulator designed to help students manage their finances and make better financial decisions within a limited budget.

## Features
- Financial Health Dashboard
- Income and Expense Management
- Daridryam Alert
- What-If Simulator
- Savings Goals
- Spending Analysis
- Future Me Projections

## Technologies Used
- Java
- Java Swing and AWT
- MySQL
- JDBC
- MySQL Connector/J
